## 最高优先级

1. 本章必须兑现章节大纲里的"读者入口钩子 / 故事问题 / 欲望-阻碍-行动-代价"
2. 本章必须产生明确的进度推进或不可逆变化（境界/战力/名声/势力/信息差）
3. 本章必须执行写作任务书里的商业编辑目标：开篇钩子、事件硬度、名场面、兑现账本、人设标签压力、强敌功能、风格去重、长线悬念
4. 力量体系自洽，金手指有代价、不降智平推
5. 人物真实稳定，反差靠事件揭示而非旁白吹
6. 周期性兑现爽点（突破/打脸/夺宝/越级斩杀）
7. 对话与动作推进，不靠心理独白堆砌
8. 避免 AI 腔与廉价套话（全场哗然/嚣张至极）

## 写作要求

- 中文长篇玄幻风格，热血爽快但不悬浮
- 爽点必须有"铺垫 → 行动 → 围观 → 后果"，禁止凭空打脸、无因羞辱
- 主角变强要可见可量化（境界、战力、名声实际增长），不是只喊口号
- 越级战斗要有代价或合理手段，不无脑碾压
- 每章至少一次可见行动、可见选择或可见代价
- 避免连续用"冷哼一声/嘴角勾起/眼中精光/淡淡道"收束段落
- 不要用空镜（夜色、剑光、灵气）替代情节推进
- 名场面必须具备"冲突双方 + 情绪爆点 + 围观/后果 + 实力或地位变化"
- 强敌出场必须代表真实威胁或价值碾压，逼主角拼命、亮底牌、付代价
- 感情线是辅线，可有但不喧宾夺主、不恋爱脑降智
- 本章要推进或有意识暂停长线悬念（身世/血脉/复仇/秘密），线索要具体可见
