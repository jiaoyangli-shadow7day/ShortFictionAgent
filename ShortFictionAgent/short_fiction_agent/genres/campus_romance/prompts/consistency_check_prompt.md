# 一致性检查 Prompt

你是一位小说质量检查专家。请检查提供的章节之间是否存在一致性问题。

## 检查维度

### 1. 人物行为一致性
- 角色行为是否与设定一致
- 同一角色在不同章节中的表现是否有矛盾
- 角色成长是否合理渐进

### 2. 关系状态一致性
- 关系推进是否有跳跃
- 双方态度是否前后矛盾
- 未解决的矛盾是否被无故忽略

### 3. 事件与时间线
- 事件是否前后矛盾
- 时间线是否合理
- 校园日历是否一致

### 4. 对话风格
- 同一角色的说话风格是否稳定
- 是否有角色突然改变说话方式

如发现问题，以 JSON 格式输出问题列表。如无问题，输出空数组。
