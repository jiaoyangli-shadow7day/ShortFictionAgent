# 青春校园恋爱写作规则

## 一、感情推进规则

1. 感情必须渐进，不允许突然喜欢、突然表白、突然亲密。
2. 每章只允许有一个小幅关系变化，除非大纲明确允许重大转折。
3. 关系推进必须由事件、细节、误会、共同经历推动。
4. 角色可以嘴硬，但行为要暴露真实情绪。
5. 暧昧感优先通过动作、停顿、眼神、物件和场景表达，不要直接解释。
6. 当前关系阶段没有允许之前，禁止表白、牵手、亲吻、同居等明显成人化或亲密化剧情。
7. 不能为了撒糖牺牲人物逻辑。

## 二、校园真实感规则

1. 场景必须符合中国校园生活。
2. 可以出现早读、晚自习、月考、运动会、社团、食堂、操场、教学楼、班主任、家长会、校服、座位、试卷、粉笔灰、广播、值日等元素。
3. 不要写成成人职场。
4. 不要写成霸总文学。
5. 学生说话要自然，不要像职场汇报。
6. 学业压力、家庭期待、同学关系要自然存在。
7. 校园生活细节必须服务人物和感情，不要堆素材。

## 三、人设稳定规则

1. 角色说话风格必须稳定。
2. 角色行为必须符合其性格、防御机制和成长阶段。
3. 不允许为了发糖强行降智。
4. 不允许为了制造误会强行不解释，除非有合理心理动机。
5. 男主不能突然油腻，女主不能突然恋爱脑。
6. 配角不能只做助攻工具人。

## 四、AI 腔规避规则

1. 少用"命运的齿轮开始转动"。
2. 少用"他不知道的是"。
3. 少用总结式心理旁白。
4. 少用过度工整的排比。
5. 少用短视频爆款文案语气。
6. 少用"少年少女""青春的气息"这类空泛表达。
7. 多写具体动作、物件、声音、光线、气味和细节。
8. 多写没说出口的话，而不是把心理全部解释出来。

## 五、章节钩子规则

1. 每章结尾要留下情绪期待。
2. 钩子可以是误会、约定、秘密、未说出口的话、关系变化、考试结果、家庭压力、朋友评价。
3. 不要每章都用强悬念。
4. 青春校园恋爱的钩子可以很轻，但要有余味。
5. 结尾不能靠狗血反转硬拉读者。

## 六、中长篇结构规则

1. 20 万到 50 万字的小说，前期不能过快消耗核心关系。
2. 前期要建立人物、关系张力、校园环境和核心矛盾。
3. 中期要通过共同经历、成长压力、误会、外部事件等推进关系。
4. 后期要回收伏笔，回应人物成长和情感主题。
5. 每章都要服务长期情感弧线。
6. 具体结构不固定，应由 LLM 根据本书设定动态设计。
