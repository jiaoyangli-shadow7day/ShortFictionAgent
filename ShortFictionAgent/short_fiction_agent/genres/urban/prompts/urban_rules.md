# 都市小说写作规则

本规则用于中国都市题材长篇（都市言情 / 都市逆袭，可含重生设定）。
代码只负责流程与质检，具体剧情由你根据设定动态创作。

## 一、都市真实感规则

1. 场景必须符合现代中国都市生活：写字楼、公司、商场、医院、饭局、家族、出租屋、CBD、高铁、外卖、微信、转账等。
2. 成年人的世界由**利益、身份、责任、面子**驱动，不是校园式的纯情绪。冲突要落到钱、权、位置、名声、家庭责任上。
3. 不要悬浮：豪门也有规矩与代价，逆袭要有路径与铺垫，神医/重生/系统等金手指必须有**限制与代价**，不能全知全能、降智碾压。
4. 对话像成年人：克制、有潜台词、谈条件、留余地，少用中二台词和廉价狠话。

## 二、爽点与节奏规则（都市的命门）

1. 都市靠**周期性兑现爽点**驱动追读：当众打脸、身份揭露、商战翻盘、退婚反杀、扮猪吃虎、债主反转、绝地逆袭。
2. 爽点必须有**铺垫（被小看/被羞辱/被误认）→ 行动 → 围观 → 后果**四要素，禁止凭空打脸、无因羞辱。
3. 每 3-5 章至少一次明确的小兑现，每 8-12 章一次大爆点。不要连续多章只铺垫不兑现。
4. 打脸/逆袭之后要落到**可见后果**：对方出局、合同到手、地位变化、舆论反转，而不是只爽一句嘴。

## 三、人设规则

1. 主角要有清晰的**外部目标线**（事业/复仇/守护家族/夺回属于自己的东西），不能只围绕谈恋爱。
2. 反差人设是都市的核心卖点：落魄却深藏不露、低调却手握底牌、隐忍却伺机翻盘。但反差要靠事件揭示，不靠旁白吹。
3. 反派/对手不能是纯工具人：要代表真实的利益竞争或价值碾压，逼主角亮底牌、做选择、付代价。
4. 若含**重生设定**：重生者拥有"先知优势"，但信息会因蝴蝶效应失效，不能靠背剧本一路平推；先知是起点不是终点。

## 四、感情线规则

1. 感情线与事业/权势线**交织推进**，互相成为筹码、软肋或助力，而不是两条平行线。
2. 关系推进要由事件、利益、误会、共同进退推动，可以比校园快，但不能无理由跳级或恋爱脑降智。
3. 允许成年人的亲密进展（牵手、拥抱、接吻、确认关系），关键是符合关系阶段、有铺垫、有后果。

## 五、AI 腔与套路规避

1. 避免"全场震惊/众人哗然/嚣张至极/不可一世"等廉价爽文套话，用具体反应替代。
2. 避免每章用"冷笑一声/勾了勾唇/眼神一冷/淡淡地说"收束，建立人物专属的动作与语气。
3. 不要用空镜（夜色、落地窗、红酒）替代情节推进；每章至少一次可见行动、可见选择或可见后果。

## 六、章节钩子规则

每章结尾要抛出明确的下一步问题：身份将被戳破、合同将签未签、对手将反扑、旧账将被翻出、关系将被迫摊牌。
钩子要让读者想问"然后呢/他怎么翻盘/身份会不会暴露"，而不是只留情绪余味。
