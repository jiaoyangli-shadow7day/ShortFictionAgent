## 最高优先级

1. 本章必须兑现章节大纲里的"读者入口钩子/故事问题/欲望-阻碍-行动-代价"
2. 本章必须产生明确的关系转向或不可逆信息变化（身份、利益、地位、信息差）
3. 本章必须执行写作任务书里的商业编辑目标：开篇钩子、事件硬度、名场面、兑现账本、人设标签压力、对手功能、风格去重、长线悬念
4. 事业/权势/复仇线与感情线交织推进
5. 人物真实稳定，成年人的利益与算计可信
6. 都市生活真实（职场、商战、家族、饭局、医院、CBD）
7. 对话像成年人，有潜台词
8. 避免 AI 腔与廉价爽文套话（全场震惊/嚣张至极）
9. 金手指（神医/重生/系统）必须有限制与代价，不能降智碾压
10. 支撑中长篇结构，爽点周期性兑现

## 写作要求

- 中文长篇小说风格，节奏明快但不悬浮
- 爽点必须有"铺垫 → 行动 → 围观 → 后果"，禁止凭空打脸、无因羞辱
- 对话克制有潜台词，少用中二狠话
- 用动作、物件、场面、利益变化推进，而不是心理独白堆砌
- 每章结尾要有明确追读钩子（身份将露、合同将签、对手反扑、旧账翻出、关系摊牌）
- 每章至少一次可见行动、可见选择或可见代价
- 避免连续用"冷笑一声/勾了勾唇/眼神一冷/淡淡地说"收束段落
- 不要用空镜（夜色、落地窗、红酒）替代情节推进
- 如果本章任务书要求名场面，必须具备"冲突双方 + 情绪爆点 + 围观/后果 + 关系或地位变化"
- 如果含重生设定：先知优势是起点不是终点，信息会因改变而失效，不能背剧本平推
- 如果对手出场，必须代表真实利益竞争或价值碾压，逼主角亮底牌、做选择、付代价
- 本章至少有一个动作或对话直接压到主角的人设标签（落魄/隐忍/腹黑/复仇/守护）
- 本章要推进或有意识暂停长线悬念；如果推进，线索必须具体可见
