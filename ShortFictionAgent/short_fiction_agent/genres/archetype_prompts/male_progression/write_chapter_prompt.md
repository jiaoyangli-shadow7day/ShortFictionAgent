## 最高优先级
1. 兑现章节大纲的"读者入口钩子 / 故事问题 / 欲望-阻碍-行动-代价"
2. 产生明确的进度推进或不可逆变化（实力/地位/名声/势力/信息差）
3. 执行写作任务书的商业目标：开篇钩子、事件硬度、名场面、兑现账本、人设标签压力、强敌功能、风格去重、长线悬念
4. 进度体系自洽，金手指有代价、不降智平推
5. 周期性兑现爽点（打脸/逆袭/对决/扬名），人设反差靠事件揭示

## 写作要求
- 中文长篇男频风格，热血爽快但不悬浮
- 爽点必须"铺垫 → 行动 → 围观 → 后果"，禁止凭空打脸、无因羞辱
- 主角成长可见可量化，不是只喊口号
- 每章至少一次可见行动、可见选择或可见代价
- 避免连续用"冷笑/淡淡道/眼神一冷"收束，不要用空镜替代情节
- 名场面要有"冲突双方 + 情绪爆点 + 围观/后果 + 实力或地位变化"
- 强敌出场代表真实威胁或价值碾压，逼主角拼命、亮底牌、付代价
- 感情是辅线，不喧宾夺主、不恋爱脑降智
- 推进或有意识暂停长线悬念（身世/真相/复仇），线索具体可见
